# Nook — Brand Identity & Digital Media Pack ("Fresh Botanical Capsules")

This archive contains the complete open-source brand identity, vector sources, PWA icons, wordmark lockups, and social media assets for **Nook** (`Household OS`).

## Directory Structure
- `apps/web/public/` — Drop-in PWA icons (`favicon.svg`, `favicon-32x32.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `icon-1024-master.png`, and `manifest.json`).
- `svg/` — Clean, hand-coded scalable vector masters (`icon-master-1024.svg`, `favicon.svg`, light/dark horizontal lockups, stacked badge, and Open Graph master).
- `lockups/` — High-resolution PNG wordmark lockups (Light Mode `#F4F9F5`, Dark Mode `#0F1B14`, and Stacked Vertical Badge).
- `social-and-splash/` — Open Graph preview (`1200x630`), GitHub README banner (`1280x640`), and mobile/desktop PWA launch splash screens (`1080x1920` & `1920x1080`).
- `tokens/nook-tokens.css` — CSS variables for the Fresh Botanical Capsules palette.
